# Exemple

- `clasament-columba-lipit.txt` — începutul unui clasament columba.ro lipit, cu numele, codurile și telefonul înlocuite
  cu date fictive.
- Pozele celor două pedigree-uri reale folosite la proiectare (`pedigree-compuclub.webp`,
  `pedigree-foto-5-generatii.webp`) **nu sunt în repo**: conțin numele, adresele și telefoanele unor crescători. Stau doar
  local, în `data/exemple-private/` (ignorat de git). Testele folosesc transcrierile din `test/fixtures/`.
